Use exactly these four sizes and two weights for Phase 2 additions.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 700 | 1.4 |
| Heading | 20px | 700 | 1.2 |

Rules:

- Table body cells use Body.
- Table headers, form labels, nav items, and status badge labels use Label.
- Page section headings such as "Catalog" and "Books" use Heading unless they are the only page title in the viewport.
- Do not introduce additional weights; existing 800 eyebrow styling should not be copied into new Phase 2 components.

## Phase 2 Screen Contracts

### Student Catalog

- Use a compact table/list, not a card grid or bookstore-style visual layout.
- Show columns in this order on desktop: Title, Author, Category, ISBN, Availability.
- On narrow screens, keep the same data visible by allowing horizontal table scroll or converting each row to a compact stacked row. Do not hide ISBN or availability.
- Place one search input and two filters directly above the table in a single toolbar.
- Search input searches title, author, category, and ISBN through the server-backed endpoint.
- Category filter uses known category values from catalog data; availability filter uses All availability, Available, Unavailable.
- Availability is a status badge only. Do not add borrow request buttons in Phase 2.

### Librarian Books

- Use one Books page with toolbar, table, and an add/edit form. Inline form is preferred unless existing implementation constraints make a modal simpler.
- Show columns in this order on desktop: Title, Author, Category, ISBN, Availability, Actions.
- Actions per row: Edit and Delete. Delete is disabled or replaced with blocked copy when an active-loan rule prevents deletion.
- Required form fields: Title, Author, Category, ISBN, Availability.
- Availability control is a binary select or toggle with labels Available and Unavailable.
- During edit, descriptive fields remain editable for unavailable/on-loan books; ISBN is protected when the book is unavailable or on loan.
- Eligible deletes require confirmation before the API request. The confirmation must name the action and permanence.

## Interaction States

| State | Required Behavior |
|-------|-------------------|
| Initial loading | Show a compact inline loading message inside the main content area: `Loading catalog...` or `Loading books...`. |
| Loaded with data | Render toolbar first, then result count, then table. Result count copy: `{n} books found`. |
| No matches | Render empty state heading/body from the copywriting contract below the toolbar; keep filters visible. |
| API failure | Render error state copy in an `.alert`; keep the user on the same page and allow retry by changing filters or reloading. |
| Search/filter change | Update server query parameters through the API helper; avoid client-only filtering as the source of truth. |
| Create success | Clear the add form and refresh the table; show a short inline success message: `Book added.` |
| Edit success | Exit edit mode, refresh the table, and show `Book updated.` |
| Delete confirmation accepted | Send delete request, refresh table on success, and show `Book deleted.` |
| Delete blocked | Keep the row visible and show the blocked-delete copy from the API response or the contract fallback. |
| Unauthorized write | Show the API error in `.alert`; do not hide the Books page shell abruptly. |

## Accessibility Contract

- Every input and select must have a visible label or an `aria-label` matching the copywriting contract.
- Toolbar controls must be reachable by keyboard in the order Search, Category, Availability.
- Delete confirmation must be keyboard operable. Native `window.confirm` is acceptable for Phase 2.
- Status badges must use text labels, not color alone.
- Active navigation must be exposed with `aria-current="page"` when Catalog or Books is selected.
- Table headers must use `th`; action buttons must include the book title in accessible context when practical, for example `Delete Clean Code`.
- Focus states must be visible and use the accent color.
