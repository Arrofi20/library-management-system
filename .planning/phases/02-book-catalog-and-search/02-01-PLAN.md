<threat_model>
| Threat | STRIDE | Disposition | Mitigation |
|---|---|---|---|
| Librarian-only routes exposed to students | Elevation of privilege | mitigate | Protect write routes with existing librarian guard middleware. |
| ISBN duplication or malformed ISBNs | Tampering | mitigate | Validate required ISBN format on the server and enforce unique constraint. |
| Availability status misread as loan status | Information disclosure | mitigate | Keep availability as a UI-only badge and document that loan status is handled in later phases. |
| UI/UX inconsistency causing student confusion | Spoofing / repudiation | mitigate | Follow the Phase 2 UI spec copy and keep the student page distinct from librarian pages. |
</threat_model>
