| Threat | STRIDE | Disposition | Mitigation |
|---|---|---|---|
| Librarians returning non-active loans | Tampering | mitigate | Only allow return actions on loans with status `active`.
| Returned book not becoming available | Tampering | mitigate | Update `books.available` in the same transaction as the loan return.
| Students seeing stale loan state | Information disclosure | mitigate | Refresh loan data after return operations and ensure returned loans stay visible.
