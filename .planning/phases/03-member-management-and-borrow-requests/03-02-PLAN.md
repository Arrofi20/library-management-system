<threat_model>
| Threat | STRIDE | Disposition | Mitigation |
|---|---|---|---|
| Students request unavailable books | Tampering | mitigate | Enforce availability at the API boundary and refresh catalog state after request attempts. |
| Duplicate or overlapping requests | Tampering | mitigate | Block duplicate pending and active-loan requests for the same student/book pair at API submission time. |
| Inactive members bypass borrow restrictions | Elevation of privilege | mitigate | Check `member_active` on every borrow request create action. |
</threat_model>
