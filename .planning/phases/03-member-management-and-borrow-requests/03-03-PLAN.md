<threat_model>
| Threat | STRIDE | Disposition | Mitigation |
|---|---|---|---|
| Approving a request for an unavailable book | Tampering | mitigate | Validate availability and request state before creating a loan. |
| Race conditions between approvals | Elevation of privilege | mitigate | Use atomic database updates in approval logic and re-check availability before loan creation. |
| Rejection notes expose internal text | Information disclosure | accept | Keep notes visible only to the requesting student and the librarian UI. |
</threat_model>
